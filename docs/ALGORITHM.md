# 潮签算法说明

本文只讲规则, 不举真实卦例。凡写「本项目选择」「工程参数」的地方, 都是实现上的取舍, 不是古籍定量结论。
所有输出都是**传统规则下的参考线索, 未经科学验证, 不是事件发生概率**。

## 0. 数据流

```
出生信息 ──bazi.build_profile──▶ 命盘 profile
                                      │
日期时间 ──almanac──▶ 黄历/节气 ──┬──▶ natal.bazi_today ──┐
                                  ├──▶ meihua.meihua_cast  │
                                  ├──▶ qimen.day_summary ──┼──▶ daily.domain_scores ──▶ 叙事材料 facts
                                  └──▶ natal.watch/lucky ──┘                              │
                                                                     规则兜底文案 ◀───────┤
                                                       (可选) llm 改写 ──▶ guards 护栏 ──┘

问题文本 ──contract.build_event_contract──▶ liuyao.cast ──▶ timing.build_timeline
         ──▶ contract.freeze_prediction ──▶ (可选) llm 解语 ──▶ cast/contract 护栏
```

## 1. 黄历与节气(`chaoqian.almanac`)

- 全部由 [lunar-python](https://github.com/6tail/lunar-python) 计算: 农历、干支、二十四节气、值日(建除十二神)、
  二十八宿、冲煞、彭祖百忌、每日宜忌、喜神 / 财神方位、黄道黑道时辰。
- **年柱、月柱精确到交节时刻**(立春、各「节」), 与命盘同口径; 另给一个整日取整的月柱 `gz_month_day`,
  供按日粒度的留意日 / 吉日扫描使用, 保证「今天」与「未来 30 天」两处口径一致。
- 子时: 一天有早子(00–01)与晚子(23–01)两条, 时辰表保留晚子时那条。
- 月运按**公历月**切换, 内部按流月分段(一个公历月恰跨两个流月), 换月日期由引擎标注。

## 2. 八字排盘(`chaoqian.bazi`)

1. **真太阳时** = 钟表时间 + 均时差(NOAA 分数年近似) + 经度修正(4 分钟 / 度, 减去时区中央经线)。
2. 四柱: lunar-python 精确交节; `day_boundary=midnight` 时按 0 点换日(子初换日可改为 `zi`)。
3. 藏干(本气 / 中气 / 余气)按《渊海子平·地支藏遁歌》, 权重(如 .6 / .25 / .15)为本项目约定。
4. 五行强弱: 显干各 1.0 + 各支藏干合计 1.0 + 月令藏干追加 0.8; 「生扶 ≥ 克泄耗 × 1.15」判偏强。
   - 偏强: 比劫 -.75、印 -.85、食伤 +.8、财 +.65、官杀 +.15;
   - 偏弱: 比劫 +.8、印 +.7、食伤 -.45、财 -.65、官杀 -.75;
   - 调候: 亥子丑月火 +.45、土 +.15、水 -.2; 巳午未月水 +.45、金 +.1、火 -.2。
   - 权重截断到 [-1, 1]; ≥ .4 为喜用, ≤ -.4 为忌。这是**透明的启发式**, 不是格局派的完整判断。
5. 起运: 阳年男 / 阴年女顺排(取出生后下一节), 反之逆排(取出生前上一节); 两端同作真太阳时校正;
   分钟法 3 天折 1 年、1 天折 4 个月、1 时辰折 10 天。八步大运, 每步十年。
6. profile 不回写原始出生日期 / 钟表时间, 但其中的经纬度、真太阳时、精确起运时刻、四柱等仍能反推出生信息, 属敏感数据;
   `redact_profile()` 只去掉坐标和精确时刻(连同大运起止年份), 不能防反推: 四柱本身就能把出生日期缩到极少几个候选;
   用它算日签时不计「大运喜忌」。

## 3. 八字日运(`chaoqian.natal.bazi_today`)

逐条留痕(`components`), 合计分 `score`, 潮位 `tide = clamp(round(5.5 + score), 1, 10)`:
1–3 退潮、4–6 平潮、7–8 涨潮、9–10 大潮。

| 规则 | 分值 |
|---|---|
| 日干喜忌 | 1.5 × 日干五行权重 |
| 日支藏干喜忌 | Σ 藏干比例 × 五行权重 |
| 天干五合 / 天干相冲(与命局四干) | +.7 / -.7 |
| 地支六冲 | 日支 -1.4, 其余 -.65 |
| 地支六合 | 日支 +1.0, 其余 +.7 |
| 害 / 破 / 刑 / 自刑 | -.45 / -.3 / -.45 / -.3 |
| 三合成局(当日支补齐命中两支) | 1.2 × 局五行权重 |
| 当日支落命局旬空 | -.6 |
| 流年 / 流月 / 大运喜忌 | .35 / .55 / .35 × (干权重 + 支权重) |

## 4. 留意日与吉日(`chaoqian.natal`)

- **留意日**标签: 劫财透干、冲夫妻宫(冲日支)、冲本命(冲年支)、月破(冲月支)、空亡(落命局旬空)、
  忌神旺(日干五行权重 ≤ -.55)。空亡 / 忌神旺是弱信号, 单独出现不报; ≥2 个标签为「重」。
- **吉日**标签: 财星日(日干为正 / 偏财)、天乙贵人(取「甲戊庚牛羊」派)、禄神、文昌、桃花(弱信号)。
- 凶吉冲突时凶优先: 有留意标签的日子不进吉日名单。

## 5. 梅花易数 · 时间起卦(`chaoqian.meihua`)

上卦 = (年支数 + 农历月 + 农历日) mod 8, 下卦 = (上式 + 时支数) mod 8(余 0 作 8, 先天八卦序),
动爻 = 下式 mod 6(余 0 作 6); 另出变卦、互卦。卦辞 / 爻辞取《周易》原文, 按(上卦, 下卦)二元组查表。

## 6. 奇门遁甲(`chaoqian.qimen`)

- 时家奇门 · **转盘 · 拆补法**: 节气定阴阳遁与上中下元局数(定局表见源码), 日柱所在五日元的符头定元。
- 地盘三奇六仪自局数宫起布(阳顺阴逆); 旬首定值符、值使; 值符随时干转盘, 天盘干随星走; 值使随时支飞宫; 八神自值符落宫起布。中五寄坤二。
- **时段评分**(07–23 点每两小时一局): 值使门 吉门 +2 / 凶门 -2; 值使宫星 天心天任天辅 +1、天芮天蓬 -1;
  神 太阴六合九地九天 +.5、白虎玄武螣蛇 -.5; 门迫 -1。≥2 为顺(2), ≤-1 为缓(0), 其余为平(1)。
- **格局叠加**(只看值使宫与值符宫): 大吉 +3 / 吉 +2 / 中 0 / 凶 -2 / 大凶 -3, 乘 0.5, 值符宫再乘 0.5, 总修正封顶 ±1.5。
  这三个系数是**工程参数**, 目的是不让格局盖过门的主导权重。全局凶格(伏吟、反吟、六仪击刑)与门迫 / 门制只出文字不加减分。
- **五不遇时**: 判据**合论干支**(日干 + 时柱干支合十时柱表: 甲日庚午、乙日辛巳、丙日壬辰、丁日癸卯、戊日甲寅、
  己日乙丑、庚日丙子、辛日丁酉、壬日戊申、癸日己未), 依《御定奇门宝鉴·释义四十四则》「只论干为七杀, 合论干支为五不遇时」。
  命中时段基础分压到 -9, 永不进吉时段与「相对最好时段」候选。
- 全天风格: 顺时段占比 ≥ 50% 宜主动推进, ≥ 25% 先观察后推进, 否则宜守不宜攻。
  没有顺时段时, 取全天分数最高的非五不遇时段作参考, 并标 `dir_range_is_best=False`。

## 7. 奇门格局(`chaoqian.qimen_geju`)

每条规则带 `verified`: confirmed / partial / conflict(只接入已定案口径)。unverified 条目不进引擎, 留档在 `_NOT_IMPLEMENTED`。
覆盖: 十干克应(青龙返首、飞鸟跌穴、白虎猖狂、青龙逃走、太白入荧、荧入太白、螣蛇夭矫、朱雀投江、大格、刑格、上格、
大悖入刑、火悖地户)、悖格四式、三奇升殿 / 得使(校旬首之仪) / 入墓、六仪击刑、门迫 / 门制、三诈五假、九遁、驿马、
星 / 门 / 干 伏吟反吟、五不遇时。出处写在每条规则的 `source` 字段。

## 8. 六爻(`chaoqian.liuyao`)

1. **起卦**: 六次掷三枚硬币(自下而上), 正面数 3 老阳(动)、0 老阴(动)、1 少阳、2 少阴。`coins` 可复用原卦重算新期限。
2. **装卦**: 京房八宫定宫与世应(本宫世六, 一至五世, 游魂世四, 归魂世三); 京房纳甲配干支; 六亲以宫五行定; 六神按日干起。
3. **用神**: 事业 官鬼, 财务 妻财, 亲子 子孙, 文书 父母, 身心 / 其他 世爻; 感情类随问卦人性别取(女 官鬼、男 妻财), 必须给出性别。
   候选池前置顺序: 本卦 → 变卦 → 日辰 / 月建 → 伏神(《增删卜易》「用神不上卦, 先取变卦, 再取日月, 日月亦非才寻伏神」)。
   同组内按 动静 → 临日月 → 飞伏关系 → 近世 → 旺衰 → 爻位 排序(《卜筮正宗》「两爻一动一静, 取动者为用神」)。
4. **旺衰打分**(`_line_strength`): 临月建 +2、月建生 +1、月建克 -2、爻克月建(囚) -1、月破 -2; 临日辰 +2、日辰生 +1、日辰克 -1;
   日冲: 月令旺相且非月破、非动爻为**暗动** +.5, 否则 -.5。
   静爻旬空: 旺 / 相 / 得日辰生为**假空** -.5, 其余为**真空** -1.5(「相」归假空、休囚归真空是本项目选择)。
   动爻: +.5 + 回头生 +2 / 回头克 -2 / 同气 +.5 / 化泄化耗 -.5 / 化进神 +1.5 / 化退神 -1.5; 动空不扣空亡分。
5. **动爻作用条件**(`_line_action`): 有力(月令旺相、得日辰生扶、回头生 / 化进) / 受制(回头克、休囚化退、休囚化绝、休囚又被日月克) /
   待时(动空、化空、月破、日合、动化合、非土入墓) / 未定。生克用神时按 有力 1.0、未定 0.6、待时 0、受制 0 计入 ±1.2。
   旺相或得日辰生扶的明动爻, 若待时只有空亡类, 判有力(《增删卜易》「元神旺动, 临空化空」)。
6. **伏神**: 本宫首卦同爻位取伏, 本卦同位为飞。飞伏四句口诀: 飞生伏 +1.5、伏克飞 +1.0、比和 0、伏生飞 -.5、飞克伏 -2.0。
   可用性三态: 无用五条任一成立 → blocked; 旺相 / 临日月 / 飞神被制 / 飞生伏 → available; 其余 conditional; 旺相而空降为 conditional。
7. **三合 / 半合**: 来源池含动爻、变爻、静爻、日辰、月建。三支俱全且 ≥2 爻动成局; 缺一支而两支皆动为「虚一待用」;
   成员值旬空 / 月破判「待填实」, 入日墓判「待冲墓开」。半合只收含中神的八组, 须至少一爻动。
   局对用神加减分: 用神在局 +.6×基数、局同类 +.5×、局生用神 +.4×、局克用神 -.6×、用神泄于局 -.2×(三合基数 2、半合 1),
   非「成局即发」减半, 再按化神力量微调, 截断到 ±基数。
8. **卦体**: 六合卦 +.5、六冲卦 -.5。最终 ≥2 为强、≥ -.5 为平, 否则为弱。
9. **应期候选**(逐日扫描时限窗):
   静爻逢值逢冲、动爻逢值逢合; 空亡四态(冲空转实 / 动空冲实 / 冲空起用 / 填实出空); 月破逢填实 / 逢合;
   日合待冲开; 静爻逢冲按旺衰分「冲用神」(利)与「逢冲日破」(不利), 假空不作日破;
   动爻逢冲、暗动被引发、逢变爻; 入日墓 / 化墓的「冲开墓库」; 弱用神的生扶日、长生日、帝旺日;
   伏神的冲飞神日、日克飞神、飞神墓绝日、飞神出空、日生伏神、伏神帝旺; 三合待填实 / 待冲墓开 / 虚一待用之日。
   用神本身待时或受制时, 利日一律降为「关键(critical)」并注明「单项触发不代表已恢复作用或事件完成」。
   每项带 `kind`(favorable / critical / unfavorable)与 `basis`(出处)。

## 9. 分阶段时间线(`chaoqian.timing`)

- 原卦、用神、强弱**一律不变**; 按准确交节时刻把期限切成若干「未来月令阶段」, 每段评估月令对原用神的生克冲(助力 / 制约 / 泄耗)。
- 同一天的多条触发合并为一个候选, 保留全部理由; 只要含不利理由, 标题即标不利(保守)。
- 每个阶段按 关键 → 不利 → 有利 各取代表日(同类按不同触发理由数、再按日期), 不编造、不均分日期。

## 10. 问事合同(`chaoqian.contract`)

- 问题类型: comparison(最大 / 比较) / choice(选哪个) / timing(何时) / trend(走势) / occurrence(会不会)。
- 可核对(verifiable)只限 occurrence / timing, 且非不利事件、否定问法须给出完成标准。
- 没给完成标准时按问题关键词补默认标准: 工作(以正式通知或实际交付为准)、学习(以正式成绩或录取结果为准)、出行(以实际成行为准)、健康(以医生或正式报告为准, 本工具不做医疗判断)、财务(以实际到账为准)、审批、签约。
- 事前倾向: 强 → yes、弱 → no、平 → undetermined; 不可核对或存在「待时」条件时一律 undetermined。
  对照基线固定为 0.5, 传统势能**不转换为成功概率**。
- 解卦文案护栏: 拦截保证 / 成功率说法、不在阶段内的年月日、无输入依据的现实细节(条件句除外)、把长期结论缩成近几天、
  把观察日写成完成承诺。

## 11. 五领域分数(`chaoqian.daily`)

- 基线 50 + (潮位 - 5) × 5; 当日干与日支藏干(×.75)的十神按向量加到 work / money / love / parent / body,
  方向由该干五行喜忌决定(中性按 .15)。伴侣领域按命主性别取配偶星: 女命官杀、男命财星; 性别未知时两组各取一半权重。
- 日支合冲刑害破对伴侣(夫妻宫加重)、亲子、身心加减; 当日支落命局旬空 work / money 各 -4。
- 奇门: 有顺时段 work +5、有生门吉方 money +3、全天宜守 work -5。天气(可选): 降雨概率 ≥75% 或最高温 ≥34℃ 身心各 -3。
- 截断到 5–95。信号带默认各领域 low 46 / high 58; `calibrate_signal_bands()` 可按某张命盘回放一年取 30 / 70 分位。
- 冲突仲裁(`reconcile_signals`): 底盘均分与奇门顺 / 缓时段数交叉, 给出「可进 / 宜守 / 弱底盘·有窗口 / 强底盘·慢时机 / 平衡」总口径。

## 12. 叙事护栏(`chaoqian.guards`)

- 日签: 星名按**词级**放行(材料里逐字出现才放行, 泛称需家族具体星名在场); 引擎材料原句豁免;
  不许把事件结果写成「卦应验 / 预测命中」; 不许断言今天的身体或情绪状态, 身心行固定用规则建议;
  推送文案在护栏之后由过滤后的 smile 派生。
- 解卦: 只做**状态互斥**(用神强弱、伏神可用性、合局成否、不利应期日期所在小句的吉顺多字词), 主语取最近的对象名,
  否定按前 4 字就近判定, 不套十神 / 六亲词表。
- 月运: 只有材料「十神线索」里列出的星才允许出现, 否则整句删掉并要求模型重写一次。

## 13. 局限

- 传统书籍只能说明文化源流, 不能代替预测验证。分数、权重、阈值多为本项目自定义, 未经实证校准。
- 只实现了时家奇门转盘拆补法一种起局法; 八字强弱为简化启发式; 六爻未完整实现元神忌神的非对称规则、通关与递归救应。
- 节气时刻以 lunar-python 的北京时间为准; 跨时区使用时请自行确认交节附近的日期归属。
